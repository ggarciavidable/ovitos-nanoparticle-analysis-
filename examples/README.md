# Example dataset

This directory contains a reduced trajectory extracted from a 10 nm diamond nanoparticle compression simulation.

The included frames correspond to the following simulation timesteps:

0        initial configuration
65000    established contact
200000   intermediate loading
377000   onset of dislocation activity
517000   advanced loading / post-yield deformation

## Files

- `example_trajectory.dump`: reduced LAMMPS trajectory containing the five frames listed above;
- `log.lammps`: log file containing the simulation parameters required by the contact-area script;
- `expected_output.dat`: representative output generated by the analysis scripts.

## Usage

1. Open `example_trajectory.dump` in OVITO.
2. Add a **Python Script Modifier**.
3. Load either `equatorRadius.py` or `strain-VergelesContactArea_ovitopyinterface.py`.
4. Process the trajectory.
5. Export the generated global attributes using **File → Export File → Table of Values**.
6. Compare the main output quantities with `expected_output.dat`.

This example is provided for demonstration and testing purposes only.
